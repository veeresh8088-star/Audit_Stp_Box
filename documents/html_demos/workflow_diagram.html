Compliance Report Status Lifecyle

Draft Initial audit run workspace configuration
Submitted Auditor finishes AI analysis and triggers report generation
Pending Review AI analysis complete; awaiting auditee/client review
Reviewed Auditee inspects findings, gaps, and compliance scores
Approved Signed report available for PDF export
Rejected Sent back to Draft status with comments
